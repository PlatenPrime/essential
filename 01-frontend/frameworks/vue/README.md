# Vue

> Актуальность: сентябрь 2026

## Роль в системе

UI-фреймворк с сильным DX и шаблонным синтаксисом. Часто выбирают за прогрессивность (можно внедрять постепенно) и ясность реактивности. Мета-слой — Nuxt.

## Что нужно знать (80/20)

- Options API vs Composition API — две модели организации логики
- Реактивность (ref/reactive) и однофайловые компоненты (SFC)
- Прогрессивный фреймворк: от виджета на странице до SPA
- Экосистема: Vue Router, Pinia, Nuxt
- Отличие от React: шаблоны и встроенная реактивность vs JSX и «рендер как функция»

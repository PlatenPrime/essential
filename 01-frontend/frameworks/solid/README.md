# Solid

> Актуальность: сентябрь 2026

## Роль в системе

Fine-grained reactivity с JSX-похожим синтаксисом. Высокий satisfaction при меньшей распространённости. Полезен как контраст к React: те же «компоненты», другая модель обновлений.

## Что нужно знать (80/20)

- Сигналы и точечные обновления DOM без virtual DOM reconciliation как в React
- Компонент выполняется один раз; реактивность — в чтениях сигналов
- Экосистема и meta (SolidStart) моложе массового React-стека
- Зачем смотреть: понимать альтернативную модель реактивности, даже если не выбираешь в проде

# Svelte

> Актуальность: сентябрь 2026

## Роль в системе

Компиляторный подход: меньше runtime в браузере, синтаксис ближе к «улучшенному HTML». Высокий satisfaction в опросах. Мета-слой — SvelteKit.

## Что нужно знать (80/20)

- Компиляция в императивные DOM-обновления vs virtual DOM
- Реактивность на уровне языка (`$`-синтаксис / runes в современных версиях)
- Меньше boilerplate, другая ментальная модель отладки
- Экосистема меньше React; найм и библиотеки — осознанный trade-off
- SvelteKit закрывает SSR/роутинг/адаптеры деплоя

# UI — интерфейс и дизайн-система

> Актуальность: сентябрь 2026

## Роль в системе

Как собирается визуальный и интерактивный слой: примитивы, паттерны, дизайн-токены, accessibility. Архитектурно важно не смешивать «красивые кнопки» с доменной логикой.

## Что нужно знать (80/20)

- Слои: токены → примитивы → паттерны → страницы
- Headless UI vs готовые kit'ы (Radix/shadcn, MUI, Ant, …)
- Композиция vs наследование стилей; controlled components
- Дизайн-система как продукт команды: версионирование, документация, ownership
- A11y встроена в UI-слой, а не «отдел QA потом»

| Развилка | О чём спор (одна строка) |
| --- | --- |

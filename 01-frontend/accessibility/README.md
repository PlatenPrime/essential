# Accessibility (a11y)

> Актуальность: сентябрь 2026

## Роль в системе

Доступность — часть качества продукта и часто юридическое требование. Архитектурно: семантика HTML, фокус, клавиатура, ARIA только когда семантики не хватает.

## Что нужно знать (80/20)

- Семантический HTML как база; ARIA — усилитель, не замена
- Клавиатура, фокус-менеджмент, видимый focus
- Контраст, размеры hit-area, motion preferences
- Тестирование: автоматические сканеры ловят мало; нужны ручные сценарии и screen reader spot-checks
- Дизайн-система должна нести a11y в примитивах

## Дочерние узлы

Запланировано: semantics, focus, aria, testing-a11y.

## Развилки

| Развилка | О чём спор (одна строка) |
| --- | --- |

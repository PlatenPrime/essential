# Rendering — модели рендера

> Актуальность: сентябрь 2026

## Роль в системе

Где и когда строится HTML/UI: только в браузере, на сервере при запросе, на билде, на edge, или гибридно. Выбор влияет на SEO, TTFB, размер бандла и где можно держать секреты.

## Что нужно знать (80/20)

- **CSR** — рендер в браузере после загрузки JS
- **SSR** — HTML на сервере на каждый запрос
- **SSG / ISR** — HTML на билде / с ревалидацией
- **Streaming / Suspense** — отдавать UI кусками
- **RSC / server components** (экосистема React) — серверный граф компонентов без клиентского JS по умолчанию
- Понимать trade-off: SEO и first paint vs интерактивность и сложность кэша/инвалидации

## Дочерние узлы

Пока нет. Конкретика — в meta-frameworks и React.

## Развилки

| Развилка | О чём спор (одна строка) |
| --- | --- |
| CSR vs SSR/SSG | Скорость интерактива и простота vs SEO/TTFB и серверная логика |
| Server Components vs «всё клиент» | Меньше JS vs новая ментальная модель границ |

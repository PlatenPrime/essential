# API styles

> Актуальность: сентябрь 2026

## Роль в системе

Как клиенты и сервисы разговаривают: ресурсы, графы запросов, RPC. Стиль API — контракт команды; менять его дороже, чем фреймворк.

## Что нужно знать (80/20)

- **REST** (и «HTTP JSON API») — дефолт большинства продуктов
- **GraphQL** — гибкие клиентские запросы, схема, сложность кэша/N+1
- **RPC** (gRPC, tRPC и др.) — жёсткие процедуры, сильная типизация, часто внутренние сервисы
- Версионирование, идемпотентность, ошибки, пагинация, совместимость
- Публичный API ≠ внутренний sync между сервисами

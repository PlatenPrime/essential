# RPC

> Актуальность: сентябрь 2026

## Роль в системе

Вызов процедур по сети с жёстким контрактом (protobuf/IDL или end-to-end types). Часто для service-to-service; tRPC — для TypeScript full-stack без отдельного OpenAPI.

## Что нужно знать (80/20)

- gRPC: HTTP/2, protobuf, стримы, codegen клиентов
- tRPC / похожие: типы из бэка на фронт в одном монорепо
- Сильная связность контракта; версионирование и совместимость критичны
- Публичный интернет чаще REST/GraphQL; RPC — внутри периметра или в контролируемых клиентах
- Ошибки, дедлайны, ретраи — часть протокола эксплуатации

## Дочерние узлы

Запланировано: grpc, trpc, idempotency.

## Развилки

| Развилка | О чём спор (одна строка) |
| --- | --- |

# Quality attributes — атрибуты качества

> Актуальность: сентябрь 2026

## Роль в системе

Язык, на котором сравнивают архитектурные варианты. Без явных атрибутов спор «какой стек лучше» бессмысленен: у каждого решения есть цена.

## Что нужно знать (80/20)

- **Latency / throughput** — время ответа и пропускная способность
- **Availability / reliability** — доступность и поведение при сбоях
- **Consistency** — насколько данные «одинаковы» между копиями и сервисами
- **Scalability** — рост нагрузки: вертикальный vs горизонтальный
- **Cost** — деньги (cloud, люди) и время доставки
- **Complexity / operability** — сколько нужно понимать, чтобы менять и чинить
- **Security / compliance** — поверхность атаки и регуляторика
- Уметь говорить: «мы платим X ради Y» — это и есть архитектурное решение

## Дочерние узлы

Пока нет. Практики измерения — в quality.

## Развилки

| Развилка | О чём спор (одна строка) |
| --- | --- |
| Consistency vs availability | CAP/PACELC на практике: что жертвуем при партиции и при норме |
| Speed of delivery vs operability | Быстрый MVP vs система, которую можно ночью чинить |

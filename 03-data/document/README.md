# Document stores

> Актуальность: сентябрь 2026

## Роль в системе

Документные СУБД (MongoDB и аналоги) для гибких или документно-ориентированных моделей. Не «анти-SQL», а другой fit под форму данных и эволюцию схемы.

## Что нужно знать (80/20)

- Документ как aggregate; вложенность vs ссылки
- Гибкость схемы vs риск «свалки» без инвариантов
- Транзакции и джойны ограничены/дороже, чем в Postgres
- Индексы и query patterns всё равно нужно проектировать
- Часто Postgres JSONB закрывает «хочу документы» без второй СУБД

## Развилки

| Развилка | О чём спор (одна строка) |
| --- | --- |
| MongoDB vs Postgres JSONB | Нативная документная модель vs один ops-стек |
| Flexible schema vs enforced schema | Скорость продукта vs долгосрочная целостность |
